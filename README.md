# 세대동행 퀴즈

MZ 퀴즈와 추억 퀴즈를 통해 서로의 세대를 알아가는 반응형 웹사이트입니다.

- 각 10문제, 정답 해설과 점수별 캐릭터 12명
- 쿠키런 폰트, 순차 모션과 카드 3D 효과
- 모바일, 키보드 입력, 동작 줄이기 설정 지원

## 실행

`python3 -m http.server 4173` 실행 후 http://localhost:4173 에 접속합니다.

## GitHub Pages

Settings → Pages에서 Deploy from a branch, main, /(root)를 선택합니다.

## 자료

일러스트는 프로젝트 제공 자료입니다. 쿠키런 글꼴은 데브시스터즈에서 제작했으며, 라이선스 전문은 assets/License_ko_en.pdf에 포함되어 있습니다. 이 저장소에 별도 오픈소스 재사용 라이선스를 부여하지 않습니다.
